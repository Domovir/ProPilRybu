# Support

Thank you for your interest in the **ProPilRybu** project.

This document explains how to get help, report problems, and contribute to improving the project.

---

# Getting Help

Before opening a new issue, please check:

* The project documentation in the `docs/` directory.
* Existing GitHub Issues.
* Existing Discussions (if enabled).

Many common questions may already have been answered.

---

# Reporting Bugs

If you believe you have found a bug:

1. Make sure you are using the latest version of the project.
2. Search existing Issues.
3. If the issue has not been reported, create a new GitHub Issue.

Please include:

* Operating system
* FFmpeg version
* Project version
* Relevant log messages
* Steps to reproduce the problem
* Expected behavior
* Actual behavior

The more information you provide, the easier it is to investigate the issue.

---

# Feature Requests

Suggestions for improvements are always welcome.

When proposing a new feature, please describe:

* The problem it solves
* Why it would be useful
* Possible implementation ideas (optional)

Well-described feature requests are much easier to evaluate.

---

# Security Issues

Please **do not report security vulnerabilities through public GitHub Issues**.

Instead, follow the process described in:

```text
SECURITY.md
```

Responsible disclosure helps protect users of the project.

---

# Documentation

Documentation improvements are highly appreciated.

Examples include:

* Correcting mistakes
* Clarifying explanations
* Improving examples
* Updating outdated information

Clear documentation is considered an important part of the project.

---

# Project Scope

ProPilRybu focuses on:

* Ubuntu Server
* RTSP video recording
* FFmpeg
* Archive management
* Automation
* System monitoring
* Technical documentation

Questions outside the scope of the project may not receive support.

---

# Response Expectations

This project is maintained in spare time.

Response times may vary depending on availability.

Bug reports and well-prepared feature requests are generally given higher priority than general support questions.

---

# Before Opening an Issue

Please verify:

* You are using a supported version.
* The documentation has been reviewed.
* Existing Issues have been searched.
* Sensitive information has been removed from logs and screenshots.

Never publish:

* Passwords
* Tokens
* Private keys
* Camera credentials
* FTP credentials
* SMTP credentials
* Real RTSP URLs containing authentication data

---

# Community

Constructive discussions, suggestions, and improvements are always welcome.

Please follow the project's `CODE_OF_CONDUCT.md` when participating.

---

# Thank You

Your feedback, ideas, bug reports, and documentation improvements help make ProPilRybu more reliable, easier to maintain, and more useful for everyone.
